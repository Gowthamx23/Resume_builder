# Resume Builder

A simple and efficient web application to create resumes.

## Installation
To install the application, clone the repository using the command:
```
git clone https://github.com/Gowthamx23/Resume_builder.git
```
Then, navigate to the project directory and install the required dependencies:
```
npm install
```

## Usage
To start the application, run:
```
npm start
```
Once the application is running, you can access it in your web browser at `http://localhost:3000`.

## Project Overview
This project aims to help users create attractive and professional resume templates easily. Users can input their details, choose from various templates, and download their resumes in PDF format.
