# Resume Builder

The Resume Builder is an open-source tool designed to generate professional resumes automatically from user input. Built with a Python backend and leveraging LaTeX for resume formatting, this application streamlines the process of creating polished, job-ready resumes with minimal effort.

## Features

- Customizable templates for every industry and career level.
- User-friendly interface for entering career history, skills, and other resume elements.
- Generates PDF resumes using high-quality LaTeX typesetting.
- Supports multilingual and content-rich resumes.

## Tech Stack

- **Backend:** Python (Flask/Django/FastAPI depending on implementation specifics).
- **Formatting:** LaTeX for high-fidelity, professional resume output.
- **Frontend:** Minimal (CLI or forms-based), extendable for web interfaces.

## Getting Started

Follow these instructions to install and run the Resume Builder on your local machine.

### Prerequisites

- Python 3.8+
- A working LaTeX distribution (e.g., TeX Live, MiKTeX, etc.) installed on your system.

### Installation

Clone the repository:
```bash
git clone https://github.com/Gowthamx23/Resume_builder.git
cd Resume_builder
```
Install the Python dependencies using pip:
```bash
pip install -r requirements.txt
```

### Usage

Run the application:
```bash
python app.py
```

Follow the prompts to input your details and generate your resume.
